# Пример оформления баг-репорта в JIRA
## Summary: При отправке PUT-запроса на несуществующий ID приходит ошибка 404.
​Preconditions (Предусловия): Пользователь не авторизован.
​

## Шаги воспроизведения:

​1. Ввести в Постмане  валидный URL. 

​
2. Выбрать PUT метод.
​

3. Ввести в тело валидные данные.

4. Отправить запрос.
​

## Expected result (Ожидаемый результат): По ТЗ должно было прийти “400 Bad Request: некорректный запрос”.


## Actual result (Фактический результат): В ответе выходит “Ошибка 404”
​

## Environment (Окружение): Chrome , Windows 11
